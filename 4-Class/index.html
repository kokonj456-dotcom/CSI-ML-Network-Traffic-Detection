Scientific Scope Delimitation (Why 4 Classes):

Exploits, Shellcode, and Privilege Escalation (U2R/R2L) were intentionally delimited from this study because Flow-level NetFlow features cannot reliably detect subtle single-packet memory corruptions without packet payloads, and severe class imbalance (<0.04% for U2R) induces misleading evaluation variance.
