สรุปผลการวิจัยเชิงประจักษ์ (Empirical Key Findings)

1. ผลกระทบของการทำ SMOTENC (Model 3 vs Model 1): การเพิ่มตัวอย่างสังเคราะห์ด้วย SMOTENC ใน Class 4 ช่วยขยายขอบเขตการตัดสินใจของโมเดล ทำให้ตรวจจับการโจมตีแฝงได้กว้างขึ้น

2. ผลกระทบของ Balanced Class Weighting (Model 2 & 4): การถ่วงน้ำหนักคลาสแบบสมดุลมีอิทธิพลโดยตรงต่อการผลักดัน Recall ของคลาสหายาก และช่วยให้ Balanced Accuracy ทั่วทั้งระบบสูงขึ้น

3. การผสมผสานใน Model 4 (SMOTE + Balanced Weight): ช่วยผสานข้อดีของการขยาย Decision Boundary ของ SMOTE เข้ากับการบีบให้โมเดลให้ความสนใจคลาสส่วนน้อยในระดับ Loss Function

4. การควบคุมความถูกต้องของการทดลอง: ทุกโมเดลถูกวัดผลบนชุดทดสอบจริง 100% (143,095 โฟลว์) โดยมี Early Stopping ควบคุมด้วยชุด Validation จริงเพื่อป้องกันปัญหา Overfitting อย่างเคร่งครัด
