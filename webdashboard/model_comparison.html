Supervised Trees (XGBoost)

เหมาะที่สุดสำหรับการจำแนกหลายคลาสและการคุม False Alarm: XGBoost ทำได้ดีเยี่ยมด้วย Accuracy 83.12% และ FPR 14.48% การใช้ SMOTENC ช่วยแก้ปัญหา Class Imbalance ในคลาส R2L ได้อย่างมีประสิทธิภาพสูงสุดโดยไม่ทำให้โมเดลเสียความแม่นยำในคลาสอื่นๆ

Deep Reconstruction (Autoencoder)

เหมาะที่สุดสำหรับ Anomaly Detection บนข้อมูลธรรมชาติ: Autoencoder บนข้อมูลดิบทำ F1-score ได้ 81.59% และตรวจจับ R2L ได้สูงถึง 84.26% โดยมี FPR เพียง 20.12% การปรับแต่งค่าน้ำหนัก Loss หรือสังเคราะห์ข้อมูลกลับทำให้โครงสร้าง Latent Space บิดเบือน

Tree Ensembles (Isolation Forest)

เหมาะสำหรับการตรวจจับแบบ Unsupervised บน Normal-Only: ผลลัพธ์ล่าสุดจาก result.json แสดงให้เห็นว่าการฝึก Isolation Forest เฉพาะ Normal-only สามารถคุม FPR ได้เหลือ 12.01% และได้ F1-score 83.28% หากนำไปใช้ตรวจสอบเบื้องต้น (First-tier Filtering) จะช่วยกรองทราฟฟิกได้อย่างรวดเร็ว
