คำอธิบายกลไกทางคณิตศาสตร์และพฤติกรรมทราฟฟิกระหว่าง Unsupervised Anomaly vs Supervised Gradient Trees

พฤติกรรมของ Exploits ในโครงข่าย

การโจมตีประเภท Exploits และ Privilege Escalation มักแฝงมาในรูปแบบ Request สั้นๆ ที่ใช้โปรโตคอลมาตรฐาน เช่น HTTP/HTTPS หรือ SSH โครงสร้างของแพ็กเก็ต (Packet Duration, Byte Count, Packet Ratio) จึงกลมกลืนเป็นเนื้อเดียวกับทราฟฟิกปกติ ไม่ได้มีขนาดมหึมาเหมือน DoS หรือส่งต่อเนื่องเหมือน Port Scan

ข้อจำกัดของ Isolation Forest

Isolation Forest พึ่งพาหลักการ "ตัดแบ่งสุ่ม (Random Splits)" โดยสมมติว่า Anomaly จะถูกแยกโดดเดี่ยวได้ด้วยความลึกของกิ่งไม้ที่สั้น (Shallow Depth) แต่เมื่อ Exploits แฝงตัวอยู่ใจกลางกลุ่มข้อมูลปกติ ต้นไม้สุ่มต้องตัดแบ่งลึกมาก จึงทำให้คะแนน Anomaly Score ต่ำ และถูกเข้าใจผิดว่าเป็นข้อมูลปกติ (False Negative ถึง 63.01%)

ความได้เปรียบเด็ดขาดของ XGBoost

XGBoost เรียนรู้แบบ Supervised โดยมี Objective Function ที่ปรับเกรเดียนต์หาข้อแตกต่างระดับ Sub-feature (เช่น สัดส่วน Bytes Forward/Backward, TCP Flags, การตอบกลับแบบ Reset) จึงสามารถสร้าง Decision Boundary คดเคี้ยวล้อมกรอบ Exploit ได้อย่างสมบูรณ์แบบ ทำให้ตรวจจับได้ถึง 92.72%

บทสรุปยืนยันประสิทธิภาพและการนำไปใช้งานจริง (SOC Verdict)
คำตอบเชิงประจักษ์สำหรับการยืนยันประสิทธิภาพของ XGBoost ในงานตรวจจับแบบ 2 คลาส
XGBoost Confirmed Winner

จากการทดสอบเปรียบเทียบบนชุดข้อมูลทดสอบอิสระ (~142,000 - 143,000 โฟลว์) สามารถยืนยันได้อย่างหนักแน่น (Confirmed) ว่า XGBoost มีประสิทธิภาพเหนือกว่า Isolation Forest อย่างชัดเจนในงาน 2-Class Detection (Normal vs Attack) โดยมีข้อพิสูจน์ 3 ประการหลัก:

  1. ความปลอดภัยของระบบโครงข่าย (Network Security): XGBoost มี False Negative เพียง 6.84% เทียบกับ Isolation Forest ที่ปล่อยให้การโจมตีหลุดรอดไปถึง 23.11% หมายความว่าหากใช้ Isolation Forest ทุกๆ 4 การโจมตี จะมี 1 การโจมตีที่ผ่านเข้าสู่ระบบได้สำเร็จ
  2. ความครอบคลุมภัยคุกคามชั้นสูง: ในหมวดหมู่ Exploits ซึ่งเป็นภัยคุกคามร้ายแรงอันดับต้นๆ XGBoost ดักจับได้ 92.72% ขณะที่ Isolation Forest ทำได้เพียง 36.99%
  3. ความสมดุลของการแจ้งเตือน: False Positive Rate ของ XGBoost อยู่ที่ 14.48% ซึ่งใกล้เคียงกับ Isolation Forest (12.01%) โดยไม่สร้างภาระ Alert Fatigue ที่แตกต่างกันอย่างมีนัยสำคัญแก่เจ้าหน้าที่ SOC
คำแนะนำสำหรับ Production Architecture: ในระบบตรวจจับแบบ 2 คลาส ควรเลือกใช้ XGBoost (Model 3: SMOTENC) เป็นโมเดลหลัก (Primary Classifier) ส่วน Isolation Forest เหมาะสำหรับทำหน้าที่เป็น Lightweight Anomaly Filter ด่านแรกสำหรับคัดกรองทราฟฟิกปริมาณมหาศาลเท่านั้น
